A home for your skills

让技能文档，
有一个清楚的家。

在同一个 Mac 工作区整理技能文档、连接工具，检查链接状态。哪些文件夹可以访问，由你选择。

开始了解使用方法

整理本地技能

浏览 Markdown 技能文档与附件，编辑内容，检查库中需要处理的项目。

审阅工具连接

连接共享技能源与 Agent 目录，审阅链接变更，再检查外部工具是否能读取。

按需连接网络

按需配置你选择的 HTTPS Git 仓库。商店首版关闭社区技能浏览与在线导入；同步前先检查将发送的内容。

把控制权留在你的 Mac 上

OriDock 无需另建账户。目录权限、同步凭据与后台运行分别由你设置；不使用相关功能，就无需授予相应权限。

界面支持简体中文、繁体中文、英语、日语和韩语。系统翻译功能取决于 macOS 版本和已安装的语言包。

发行进度

Mac App Store 版本正在准备审核，目前没有公开下载入口。这里的功能介绍不代表已获 Apple 审核通过。

Git 服务和外部 Agent 是独立产品，有各自的访问要求、服务条款和隐私做法。
