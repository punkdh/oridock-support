一步一步，把工作区接好。

先选择文件夹，再检查连接。启用同步前，确认仓库中没有不想上传的内容。

1. 选择允许访问的文件夹

  1. 打开 OriDock 的设置，进入“目录授权”。
  2. 为“共享技能源”选择存放技能文档的具体文件夹；需要同步时，再连接“同步仓库”。
  3. 按需连接各个 Agent 的技能目录与项目目录。若需要查看 Codex 使用情况，单独连接会话日志；这项授权为只读且可选。
  4. 出现“授权已过期”“目录或磁盘不可用”时，先确认磁盘已连接，再点击“重新授权…”选择原文件夹。

不必选择整个用户主目录。选择隐藏目录时，可以在文件选择窗口使用 ⌘⇧G 输入路径。断开授权会停止 OriDock 后续访问，不会删除文件。

连接 Agent 前先审阅变更；连接后应在对应 Agent 中检查技能能否读取。Agent 自身也需要访问共享源目录的权限。

2. 配置 HTTPS Git 同步

  1. 连接正确的本地同步仓库，确认远端地址属于你想使用的仓库。Mac App Store 版使用 HTTPS；不要填入 SSH 地址。
  2. 在设置的“HTTPS Git 凭据”中，填写不带密码或令牌的远端 HTTPS 地址、用户名和访问令牌。令牌权限尽量仅限目标仓库。
  3. 点击“保存到钥匙串”。不要把令牌写进仓库地址、技能文档或提交信息。
  4. 在同步页面设置“提交作者名称”和“提交作者邮箱”，选择“仅为此仓库保存作者”。作者信息会进入 Git 提交记录。
  5. 第一次同步前检查本地内容、远端仓库和分支。先用少量不含敏感信息的文件验证同步。

认证失败时，检查令牌是否过期及是否有相应仓库权限，再替换或重新连接凭据。“移除已存凭据”删除 OriDock 保存的相应登录信息；若令牌可能泄露，还需到 Git 服务撤销它。

仓库可见性很重要

同步会发送仓库内容与提交信息。公开远端可能让内容公开。删除本地文件不一定删除远端历史；请使用 Git 服务自己的管理工具处理。

遇到冲突时，先保留本地改动，在仓库中解决冲突后再同步。选择以远端替换本地状态前，应先检查恢复副本，不要仅为消除错误而反复重置。

3. 需要时才启用后台同步

  1. 先在窗口中完成目录授权、凭据配置和手动同步测试。
  2. 确认旧版 OriDock 的后台任务已停止，或从未安装过旧版。
  3. 在设置中点击“启用后台同步”；如显示需要批准，点击“打开系统设置”，在 macOS 的登录项与后台活动设置中允许 OriDock。
  4. 确认 OriDock 显示后台已启用；使用测试文件检查实际同步结果。

想停止时，在 OriDock 点击“停用后台同步”，并检查系统设置中的状态。仅关闭窗口不等于停用后台服务。权限失效时同步会暂停；睡眠、断网或系统繁忙可能延后执行。

4. 迁移旧库与保留备份

  1. 停止旧版、新版及所有正在写入这些目录的后台程序。
  2. 打开“数据迁移”，选择实际旧库来源和导入父目录，先执行只读预览。不要选择正在使用的 Git 工作区作为目标。
  3. 审阅文件清单与空间需求，再确认复制。请至少为两份副本预留空间；原件、私有备份和迁移记录会保留。
  4. 复制完成后，重新授权导入库，重新连接凭据，审阅并重建 Agent 链接。复制不会自动启用同步、凭据或后台服务。
  5. 检查技能内容、外部 Agent 读取和同步结果，再完成迁移向导中的确认。

设置导入只允许显示的语言、字体与非秘密代理字段；导入代理设置前先关闭代理。账户、密码、令牌、目录授权与启用状态不会自动导入。

回滚会把导入副本保留到恢复目录；它不代表所有副本已删除。副本变化或事务记录异常时，先保留原件、备份和恢复记录，避免手工混合覆盖。确认不再需要后，再自行清理备份与外部副本。

常见问题

扫描结果为空，是否没有技能或使用记录？

先检查目录授权、磁盘连接和扫描是否完整。未授权、部分扫描或失败不能当作“零使用”。

链接已建立，Agent 仍然读不到？

确认源文件仍在原处，检查链接目标和 Agent 自身的目录权限。先在连接预览中检查，再修改连接；不要随意删除已有目录。

翻译不可用？

该功能使用 Apple 的系统翻译能力，需要受支持的 macOS 和对应语言包。检查系统语言包是否可用；OriDock 不通过这一功能调用云端大模型。

怎样删除数据或停用 OriDock？

先停用后台同步、断开目录并移除已存凭据，再按需卸载应用。外部技能文件、迁移备份、Git 远端历史及部分钥匙串记录可能仍保留，需分别检查处理。

怎样更新？

Mac App Store 版通过 Mac App Store 更新。不要用官网版本覆盖正在运行的商店版本；切换发行版前先备份并完成后台服务交接。
